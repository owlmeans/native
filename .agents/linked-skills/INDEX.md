# Linked Skills

Generated by `.agents/scripts/link-skills.sh` — never edit by hand, and never
commit: the entries are symlinks into checkouts that only exist locally.

These skills belong to the repositories this one depends on. They are readable at
`.agents/linked-skills/<name>/SKILL.md` and are loaded by Claude Code through
`.claude/skills/` like any local skill. A local skill of the same name always wins,
and a nearer dependency wins over a farther one.
